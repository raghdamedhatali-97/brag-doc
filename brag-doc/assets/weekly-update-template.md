# Weekly update template

Under 200 words. Fill from this week's entries only. Omit a section if it is empty (except Top wins).

```
Subject: Weekly update - {Name} - Week {nn} ({start date} to {end date})

Hi {Manager first name},

Here is my update for this week.

Top wins
- {Result with number} - {one-line how}
- {Result with number} - {one-line how}
- {Result with number} - {one-line how}

Progress by objective
- O1 {short title}: {what moved this week}
- O2 {short title}: {what moved this week}

Where I need help
- {Blocker} - {what would clear it}

Next week
- {Focus 1}
- {Focus 2}

Thanks,
{Name}
```

## Example

```
Subject: Weekly update - Sara Ahmed - Week 39 (21 Sep to 25 Sep)

Hi Omar,

Here is my update for this week.

Top wins
- Bank reconciliation for 3 accounts now takes 2 hours instead of 1 day - automated with Power Query
- 2027 budget template signed off by 4 of 6 department heads
- Sales ops now self-serve the revenue dashboard - 4 fewer ad-hoc requests to FP&A

Progress by objective
- O1 Month-end close: reconciliation automation live for 3 of 8 accounts
- O2 2027 budget: templates out; 4 of 6 returned

Where I need help
- Bank API access pending with IT for 2 weeks - a nudge to the IT lead would help

Next week
- Automate the next 3 reconciliations
- Chase the last 2 budget templates

Thanks,
Sara
```
